## 2. 主指标定义（分子/分母）
设：
- `TP`：有效匹配数
- `FP`：未匹配预测框数
- `FN`：未匹配 GT 数

### 2.1 目标级 Precision
- 公式：`Precision = TP / (TP + FP)`
- 含义：所有报警框里，真正命中的比例。

### 2.2 目标级 Recall
- 公式：`Recall = TP / (TP + FN)`
- 含义：所有真实缺陷里，被检出的比例。

### 2.3 mAP@0.5
- 每个类别在 `IoU=0.5` 下计算 AP（101 点插值 AP，AP_101）
- 再对类别取平均：
- 公式：`mAP@0.5 = mean(AP_101_cls@IoU=0.5)`

### 2.4 mAP@0.5:0.95
- 在 IoU 阈值集合 `{0.50,0.55,...,0.95}` 上分别计算 AP_101
- 再对 IoU 阈值与类别取平均：
- 公式：`mAP@0.5:0.95 = mean_{iou in 0.50:0.05:0.95}( mean_cls(AP_101_cls@iou) )`

## 3. 补充指标定义

### 3.1 分尺度 Recall
设某尺度桶（如 `s<16`）内：
- `GT_bucket`：该桶内 GT 数
- `TP_bucket`：该桶内匹配到的 GT 数

公式：
- `Recall_bucket = TP_bucket / GT_bucket`

### 3.2 图像级误报率（image_fp_rate）
图像级四格定义：
- `img_gt0_pred1`：该图无 GT 但有预测
- `img_gt0_pred0`：该图无 GT 且无预测

公式：
- `image_fp_rate = img_gt0_pred1 / (img_gt0_pred1 + img_gt0_pred0)`

## 4. FN/FP 机制统计口径（当前实现）
- `FN_no_response`：无同类候选或候选响应极弱
- `FN_low_score`：有候选但分数低于阈值
- `FN_regression_poor`：候选分数可用但框回归不足（IoU 不达标）
- `FN_postproc_suppressed`：后处理后仍未命中（压制/竞争导致）

FP 结构：
- `FP_unmatched`：与任意 GT 最大 IoU 低于阈值
- `FP_pred_dup`：同一 GT 被多个预测覆盖导致冗余 FP
- `FP_both`：同时满足 unmatched 与 pred_dup
- `FP_other`：其余 FP
